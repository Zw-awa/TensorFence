# Security Policy

[English](./SECURITY.md) | [简体中文](./SECURITY.zh-CN.md)

## Reporting a Vulnerability

If you discover a security issue, do not open a public issue.
Use GitHub's private security advisory flow for the repository.

Please include:

- a short summary
- affected version or commit
- reproduction steps
- impact assessment
- any suggested mitigation

## What Counts as Security-Relevant

- code execution risks
- unsafe file handling
- credential leakage
- supply-chain concerns
- data exposure in generated reports

## Response Expectations

Security reports will be handled privately and reviewed as soon as practical.
